# M0 related-work matrix

**Scope:** targeted first-pass overlap screen for M0–M2. It is not a systematic review and does not establish novelty. The algorithm under test is a scalar continuous-time recurrent ODE with lazy local integration triggered by accumulated weighted neighbor changes and a local drift bound. This pilot uses synthetic graphs and makes no biological claim.

## M0 conclusion

The broad components—continuous-time neural dynamics, event-driven simulation, hybrid execution, and adaptive recurrent compute—have clear prior art. Any later novelty claim must name the narrow local scheduling/error-control mechanism and show a reproducible advantage over both conventional adaptive ODE solving and event-driven baselines. This matrix is a targeted overlap map, not a novelty clearance. The pre-registered E1 result cannot establish biological topology value (E2) or downstream learning benefit (E3).
